This category (directory) is for unit tests.
Each sub-category tests a single function.


### Prefix
The first character of the prefix (sub-category) can be:
- `00` - Tests for `get_options`.
- `01` - Tests for `set_color_for_all`.
- `02` - Tests for `is_color_enabled`.
- `03` - Tests for `get_color`.
- `04` - Tests for `color_lines`.
- `05` - Tests for `color_warning`.
- `06` - Tests for `color_error`.
- `07` - Tests for `color_fatal`.
- `08` - Tests for `color_hint`.
- `09` - Tests for color getters for the summary.
- `10` - Tests for `get_summary_mode`.
- `11` - Tests for `is_hint_enabled`.
